claude code CLI 应用形态上是REPL，REPL最常见的Node.js 的  REPL  模块（ node  命令本身）
具有以下特点：
1. 交互循环（Read-Eval-Print Loop）
这是最根本的特征：应用启动后进入一个无限循环，持续等待用户输入。

2. 维护内部状态/上下文
REPL 会保持会话期间的所有变量、函数、历史记录，上下文在多次输入间持久存在。

3. 内置元命令（Meta-Commands）
以特殊前缀（如 . 或 /）开头的命令，用于控制 REPL 本身的行为，而非执行业务逻辑。

4. 命令行参数模式 vs 交互模式
REPL 类应用通常支持两种启动方式。

5. 使用 readline 处理输入
底层依赖 Node.js 的 readline 模块，提供行编辑、历史记录和自动补全。

6. 命令分发与解析
输入字符串后，REPL 需要解析并路由到不同的处理逻辑。

7. 异常处理不崩溃
REPL 必须捕获所有错误，打印错误信息后继续运行，而不是整个进程退出。

8. 可编程性与嵌入能力
Node.js REPL 可以被其他应用嵌入使用，提供交互式调试能力
