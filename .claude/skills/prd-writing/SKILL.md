# PRD Writing

创建 PRD 骨架草稿，并通过 grill-me 逐节审查，迭代完善直至无分歧。

## 工作流

1. **创建骨架草稿**：基于 `assets/prd-template.md` 生成 PRD 骨架，结合用户提供的背景、目标用户与已有素材，填充各章节的初步内容。
2. **逐节审查（调用 grill-me）**：对以下每个部分调用 `grill-me` skill，检查矛盾点、发掘潜在问题：
   - 背景
   - 需求（功能性需求 / 非功能性需求）
   - 名词解释
   - 核心问题
   - 方案设计
   - 模块
   - 数据流向
   - 业务规则
3. **迭代完善**：根据 grill-me 审查中暴露的分歧与潜在问题，更新 PRD 对应章节，再回到步骤 2 继续审查，直到所有部分无任何分歧。

## 审查要点

- 需求是否与背景呼应、无冲突
- 功能性需求与非功能性需求是否覆盖完整
- 方案设计是否满足全部需求
- 模块划分、数据流向、业务规则是否自洽
- 名词解释是否消除了歧义

## 完成标准

- 骨架模板中所有章节均有内容
- grill-me 审查后无未解决的分歧或潜在问题
- 用户确认 PRD 定稿
